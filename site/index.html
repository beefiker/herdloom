Chat

Read the work, not the scrollback.

Every turn reads like a conversation, straight from the agent's own session file. Commands, edits and reasoning fold into one quiet line you can open when you care.

  • Worked for 2m 36s · 2 edits · 1 command — the whole turn at a glance, every call one tap away.
  • Markdown, code blocks and tables render; copy any answer as Markdown or plain text.
  • A file path in an answer opens in a viewer: images, video, PDF or text, right there.
Prompts

Answer with a tap.

Approvals, questions and plan menus become cards in the chat. Tap an option or type its number; Herdloom checks the menu is still on screen before it answers.

  • Never a stale answer. A menu that changed since you looked is refused, not guessed at.
  • Claude Code, Codex, omp and pi dialogs, including Codex's queued questions and omp's ask.
  • A password or PIN prompt gets a hidden field that types straight into the terminal.

Install

Two minutes, one line.

The installer brings anything missing, adds Herdloom as a herdr plugin, and prints a QR code for your phone when Tailscale is running.

Runs onmacOS · Linux (x64, arm64)
Needsherdr 0.9+ · Bun 1.4+ · Node 18+
LicenseMIT · free
Latestv{{version}}

  1. Run the installer

    Installs what's missing for your user only, then the plugin.

    curl -fsSL https://beefiker.github.io/herdloom/install.sh | sh

  2. Or just the plugin

    Already have herdr, Bun and Node? Install Herdloom on its own.

    herdr plugin install beefiker/herdloom

  3. Open it

    With herdr running, Herdloom starts with it. On your phone, use the tailnet address the installer printed.

    open http://localhost:7317

See it before you install it.
